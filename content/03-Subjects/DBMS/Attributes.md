An attribute is something that are properties / features of an entity or relationships.

We represent attributes with ellipse as shown.

![[Attributes Representation.png|400]]

Here, `cid`, `cname`, `caddr`, `czip` are attributes for `Customer`
and `pid`, `pname`, `price`, `ptype` are attributes for `Product`

If we have a table with these attributes as columns then each row of data is an [[Entity]]

> [!NOTE] Note
> A relationship can also have attributes. These attributes are called declarative attributes.

We have different [[Types of Attributes]].
